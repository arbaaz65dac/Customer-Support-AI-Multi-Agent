
# Delivery Policy

## Delivery Estimates

Delivery estimates depend on the shipping option, destination, and order processing status. If a verified delivery estimate is not available, customer support should explain that the estimate needs to be confirmed.

## Tracking an Order

Customers should provide their order reference when asking for order status. The application must retrieve order information from its database and must not invent tracking numbers or delivery events.

## Delayed Deliveries

If a delivery is delayed, the customer should contact support with their order reference and a description of the issue. Support staff can investigate the order and provide an update when verified information is available.
