# Returns Policy

Policy version: 1.0
Effective date: 2026-10-31
Return window days: 7

## Return window

For this sample store policy, an eligible item may be requested for return
within 7 calendar days after the order is delivered. The delivery date recorded
for the order is used to check the window. An order that has not been delivered
is not eligible for a return request.

## Eligible condition

The item should be unused, complete, and returned with its original packaging,
accessories, invoice, and any included gifts. A return request is reviewed by
support; submitting a request does not guarantee approval.

## Exclusions

Personalised items, perishables, opened hygiene products, and items marked
non-returnable on their product listing are not eligible for a change-of-mind
return. A damaged, defective, or incorrect item should be reported with a
description of the issue so support can review the appropriate remedy.

## How to request a return

Sign in and provide the order ID and reason for the request. The application
records a return request for an administrator to review. It does not arrange
pickup or approve the return automatically.
