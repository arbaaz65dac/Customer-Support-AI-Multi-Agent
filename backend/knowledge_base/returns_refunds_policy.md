
# Returns and Refunds Policy

## Return Eligibility

Return eligibility depends on the product category and the seller's applicable return terms. The assistant must not promise that a product is eligible for return unless the applicable policy confirms it.

## Refund Processing

Refund timing depends on the return approval process and the payment method. If a specific processing timeline is not documented, the assistant should not invent a number of days.

## Requesting Help

Customers who need help with a return or refund can submit a support ticket. They should include their order reference, the product involved, and a description of the issue. They should not include passwords or payment card security codes.
